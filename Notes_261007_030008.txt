تمرین اول

Git چیست و چه کاربردی دارد؟
 Git یک سیستم کنترل نسخه است که برای مدیریت و ذخیره تغییرات پروژه‌ها استفاده می‌شود. با Git می‌توان تغییرات کد را ثبت کرد و در صورت نیاز به نسخه‌های قبلی پروژه برگشت.
GitHub چیست و چه تفاوتی با Git دارد؟
 GitHub یک پلتفرم آنلاین برای نگهداری و مدیریت پروژه‌هایی است که با Git ساخته شده‌اند. به زبان ساده، Git روی سیستم ما کار می‌کند، ولی GitHub برای ذخیره و به اشتراک‌گذاری پروژه‌ها روی اینترنت استفاده می‌شود.

تمرین سوم

HTTP چیست؟
 HTTP یک پروتکل برای انتقال اطلاعات بین مرورگر و سرور وب‌سایت است.
HTTPS چیست؟
 HTTPS نسخه امن‌تر HTTP است که اطلاعات را هنگام انتقال رمزگذاری می‌کند.
تفاوت HTTP و HTTPS چیست؟
 تفاوت اصلی این است که در HTTPS اطلاعات رمزگذاری می‌شوند، اما در HTTP امنیت کمتری وجود دارد.
چرا بیشتر وب‌سایت‌ها از HTTPS استفاده می‌کنند؟
 چون باعث افزایش امنیت اطلاعات کاربران، مثل رمز عبور و اطلاعات شخصی، می‌شود و از دسترسی افراد دیگر به اطلاعات در حال انتقال جلوگیری می‌کند.

تمرین چهارم

URL چیست؟
 URL آدرس یک صفحه یا منبع در اینترنت است که برای دسترسی به آن استفاده می‌شود.

تمرین پنجم

GET چیست؟
 GET روشی برای گرفتن اطلاعات از یک وب‌سایت یا سرور است.
 مثال: وقتی در یک سایت لیست محصولات را مشاهده می‌کنیم.
POST چیست؟
 POST روشی برای فرستادن اطلاعات به یک وب‌سایت یا سرور است.
 مثال: وقتی در یک سایت فرم ثبت‌نام را پر می‌کنیم.
تفاوت GET و POST چیست؟
 GET بیشتر برای گرفتن اطلاعات استفاده می‌شود، ولی POST بیشتر برای فرستادن اطلاعات به سرور استفاده می‌شود.
GET معمولاً برای چه درخواست‌هایی استفاده می‌شود؟
 برای دریافت اطلاعات، مثل جستجوی یک محصول یا گرفتن اطلاعات یک کاربر از یک API.
POST معمولاً برای چه درخواست‌هایی استفاده می‌شود؟
 برای فرستادن اطلاعات، مثل ثبت‌نام، ورود یا ارسال یک فرم.
مثال:
 در API سایت GitHub، از GET برای دریافت اطلاعات و از POST برای ایجاد اطلاعات جدید، مثل ایجاد یک Issue، استفاده می‌شود.

تمرین ششم

JSON چیست؟
JSON یک روش ساده برای ذخیره و انتقال اطلاعات است که بیشتر در برنامه‌ها و وب‌سایت‌ها استفاده می‌شود.

XML چیست؟
XML هم روشی برای ذخیره و انتقال اطلاعات است که اطلاعات را با استفاده از تگ‌ها نمایش می‌دهد.

چه کاربردی دارند؟
برای انتقال اطلاعات بین برنامه‌ها، وب‌سایت‌ها و سرورها استفاده می‌شوند.

تفاوت JSON و XML چیست؟
JSON معمولاً کوتاه‌تر و خواناتر است، اما XML از تگ‌ها برای مشخص کردن اطلاعات استفاده می‌کند و معمولاً طولانی‌تر است.

با JSON:

{
"name": "sepinood",
"age": 19,
"studentId": 1234
}

با XML:

<Student>
<name>sepinood</name>
<age>19</age>
<studentId>1234</studentId>
</Student>
